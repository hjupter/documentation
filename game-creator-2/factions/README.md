# 🤝 Factions

Factions adds memberships, directional relationships, reputation, faction
variables, persistence, UI, and faction-aware visual scripting to Game Creator
2.

Use it for teams, guilds, alliances, rival groups, reputation ladders, target
selection, scoreboards, and any rule that depends on how one group views
another.

## Features

* Members can belong to multiple factions.
* Relationships are directional: Faction A can be Friendly toward Faction B
  while Faction B is Hostile toward Faction A.
* Reputation points map to configurable statuses such as Hostile, Neutral,
  Friendly, and Honored.
* Project faction assets, directional relationships, and reputation stances
  are managed from a dedicated Game Creator Settings panel.
* Variables and runtime relationship changes integrate with Game Creator
  Save & Load.
* Member memberships and reputation integrate with Remember.
* Built-in lists, selected-faction views, HUD elements, and scoreboards are
  available as optional installers.
* Optional Dialogue and Quests examples demonstrate supported integrations.

Factions add-ons. The standalone Factions module remains authoritative for the
local membership, relationship, reputation, UI, and persistence APIs.
{% endhint %}

{% hint style="info" %}
Abilities integration is maintained as a separate Factions-Abilities bridge.
Standalone Factions does not bundle the bridge or proprietary Abilities source.
{% endhint %}
