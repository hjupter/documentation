# Releases

## 1.0.0 — Unreleased candidate

### New

* Network weapon equip, unequip, and queued swaps.
* Tap, charge, execute, combo, cancel, and block synchronization.
* Replicated attack, defense, poise, invincibility, target, and equipment state.
* Hit, blocked, parried, and guard-broken presentation events.
* Fusion Sphere and Fusion Capsule striker shapes.
* Visual scripting tools and an event relay example.
* Late-join snapshots and reconnect input continuity.

### Important

Damage and combat outcomes remain owned by project State Authority logic.
Fusion Melee publishes the final resolved impact for presentation and does not
apply a universal damage model.

The candidate targets Unity `6000.0.60f1` and `6000.3.14f1`, Game Creator Core
`2.18.60`, Melee `2.2.14`, Photon Fusion `2.1.1` build `2177`, and Fusion Core
`1.4.0`.

{% hint style="warning" %}
Version 1.0.0 has not been released. Unity matrix, builds, package inspection,
clean installation, upgrade, and real separate-process Fusion Cloud validation
must pass before these notes become a published release.
{% endhint %}
