# 🧰 Photon Bundle

Photon Bundle 1.1.5 is an Asset Store entitlement for six Ninjutsu Games
integrations:

1. Photon Module 2 (Core) 1.5.0
2. Photon Stats 1.2.0
3. Photon Shooter 2
4. Photon Inventory 1.1.0
5. Photon Abilities 1.1.0
6. Photon Melee 2

[**Get Photon Bundle on the Unity Asset Store →**](https://www.ninjutsugames.com/go/photon-bundle?src=docs_photon_bundle_overview)

{% hint style="info" %}
The Bundle is a small customer guide. Download each included integration
separately from **My Assets** so every product can be installed and updated on
its own.
{% endhint %}

## What is included

The Bundle purchase unlocks the six integrations above. It does not embed their
runtime files, demos, or networking behavior, and it does not force every
integration to use the same version. Shooter 2 and Melee 2 use the versions
shown by their own product pages.

Photon PUN 2, Game Creator 2, and the matching Game Creator gameplay modules
are separate dependencies. Install only the gameplay modules used by your
project.

The current customer baseline uses Photon PUN 2.55, Game Creator 2 Core
2.18.60, and Photon Core 1.5.0. Photon Stats 1.2.0, Photon Inventory 1.1.0,
and Photon Abilities 1.1.0 are updated independently. Install in this order:
matching Game Creator gameplay packages, PUN, Photon Core, each add-on main
package, then its Examples package.

{% hint style="warning" %}
Photon Factions is a separate product. It belongs to the wider Photon family,
but it is not included with Photon Bundle.
{% endhint %}

## Start here

1. Follow [Install, Upgrade, and Uninstall](getting-started.md).
2. Import the matching Game Creator gameplay dependencies before their Photon
   add-ons when they are not available through the Install window.
3. Read the [Photon Module 2 multiplayer guide](../multiplayer-guide.md)
   before shipping.
