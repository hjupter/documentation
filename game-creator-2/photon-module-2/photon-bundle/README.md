# 🧰 Photon Bundle

Photon Bundle is an Asset Store entitlement for these six Ninjutsu Games integrations:

1. Photon Module 2 (Core)
2. Photon Stats
3. Photon Shooter 2
4. Photon Inventory
5. Photon Abilities
6. Photon Melee 2

[**Get Photon Bundle on the Unity Asset Store →**](https://www.ninjutsugames.com/go/photon-bundle?src=docs_photon_bundle_overview)

{% hint style="info" %}
The Bundle download is a small, versioned customer guide. Download each included integration separately from **My Assets** so Unity offers its current published package.
{% endhint %}

## What is included

The Bundle purchase unlocks the six integrations above. It does not combine them into one embedded package and does not force every integration to use the same version number.

Photon PUN 2, Game Creator 2, and the matching Game Creator gameplay modules are separate dependencies. Install only the gameplay modules your project uses.

{% hint style="warning" %}
Photon Factions is a separate product. It is part of the wider Photon integration family, but it is not included with Photon Bundle.
{% endhint %}

## Start here

1. Follow [Install, Upgrade, and Uninstall](getting-started.md).
2. Install and validate Photon Core before adding its module integrations.
3. Use each integration's documentation for its required Game Creator module and current compatibility.
4. Read the [Photon Module 2 multiplayer guide](../multiplayer-guide.md) before shipping.

## Version support

Photon Bundle and its six included integrations have independent versions:

* **Bundle version** identifies this entitlement guide.
* **Integration version** identifies the Photon Core, Stats, Shooter, Inventory, Abilities, or Melee package.
* **Installed package version** is the `@version` suffix on the integration's Game Creator install root and, where supplied, its `Version.txt`.

When requesting support, report all three relevant surfaces rather than assuming the Bundle version is the installed module version.
