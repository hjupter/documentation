# Releases

## 1.1.0 (29th July 2026)

Photon Inventory is now ready for current Game Creator 2, Photon PUN 2, and Unity 6 projects.

#### New

* Complete owner-authoritative bag snapshots for late join and reconnect recovery
* Optional Bag Network state-change logging for troubleshooting

#### Improved

* Synchronization of stacks, per-item properties, equipment, sockets, wealth, bag shape, and cooldowns
* Current examples and installers for Photon Core 1.5, Photon PUN 2.55, and Game Creator 2 Inventory 2.8.23
* Clear settings ownership across Photon Core, PUN, Game Creator Inventory, and each Bag Network component

#### Fixed

* Duplicate item types now keep their individual runtime state and attachments
* Equip and unequip changes now target the correct runtime item
* Remote clients can no longer publish state for a bag they do not own

#### Changed

* Supported Unity range is now Unity 6.3 LTS, Unity 6.4, and Unity 6.5
* Photon Inventory does not add an empty Game Creator Settings page

## 1.0.2 (23rd June 2023)
