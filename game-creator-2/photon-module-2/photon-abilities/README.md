# 🧙 Photon Abilities

Photon Abilities synchronizes the **Abilities** module for Game Creator 2 across Photon PUN 2 multiplayer sessions.

{% embed url="https://youtu.be/3HHbghDYX8o" %}

{% hint style="success" %}
[**Get Photon Abilities on the Unity Asset Store →**](https://www.ninjutsugames.com/go/photon-abilities?src=docs_photon_abilities_overview)
{% endhint %}

## Requirements

Install these packages before Photon Abilities:

1. [**Game Creator 2**](https://www.ninjutsugames.com/go/game-creator-2?src=docs_photon_abilities_requirement_gc2)
2. [**Abilities**](https://www.ninjutsugames.com/go/abilities-2?src=docs_photon_abilities_requirement_abilities)
3. [**Photon Unity Networking 2**](https://www.ninjutsugames.com/go/photon-pun-2?src=docs_photon_abilities_requirement_pun)
4. [**Photon Module 2**](https://www.ninjutsugames.com/go/photon-module-2?src=docs_photon_abilities_requirement_core)
5. [**Photon Abilities**](https://www.ninjutsugames.com/go/photon-abilities?src=docs_photon_abilities_requirement_module)

Open the **Game Creator Install** window and install Photon Core before installing the Photon Abilities submodule.

{% hint style="warning" %}
Install Ninjutsu Games modules through the **Game Creator Install** window. Do not manually extract them into a `Plugins` folder.
{% endhint %}
