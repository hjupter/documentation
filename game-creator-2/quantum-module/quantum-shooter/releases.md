# Releases

## 1.0.0

Private release validation is in progress. No public package has been published.

The release remains gated on:

- the exact pushed Quantum Core contract and compatibility descriptor;
- clean Quantum code generation and compile on every claimed Unity editor;
- rollback and checksum tests;
- sample scenes with no missing scripts;
- macOS and WebGL player proof;
- Asset Store Tools validation and exact export inspection;
- clean install, second import, upgrade, and uninstall;
- separate-process two-client Quantum Cloud proof for equipment, aiming, fire,
  reload, ammo, hits, damage, prediction, rollback, late join, and reconnect;
- terminal module and documentation CI for the exact release commits.

Photon, Game Creator, Quantum Animator, and vendor sample payloads are never
included in the product export.
