# Quantum Module

{% hint style="warning" %}
This product family is in private development. It is not available for release
and does not yet claim compatibility with any Unity editor.
{% endhint %}

The Quantum Module connects Game Creator 2 authoring and presentation to a
deterministic Photon Quantum simulation.

Quantum owns rollback-safe gameplay state. Unity and Game Creator objects send
player intent and present verified or predicted results; they do not authoritatively
change simulation frames.

## Modules

- [Quantum Stats](quantum-stats/README.md) — deterministic attributes,
  modifiers, regeneration, damage, healing, and status effects.
