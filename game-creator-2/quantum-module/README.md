# Quantum Module

The Quantum family connects Game Creator 2 authoring and presentation to Photon
Quantum's deterministic simulation.

Authoritative gameplay state lives in Quantum frames. Game Creator components,
Instructions, Conditions, Events, and Properties submit intent or display
verified results; they do not replace deterministic state.

The Core module is required by every Quantum add-on. Install only versions whose
compatibility descriptors reference the same exact Core contract.
