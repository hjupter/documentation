# Releases

## In development

Quantum Stats has no public release yet.

The first release is planned to include deterministic Stats and Attributes,
modifiers, regeneration, damage, healing, Status Effects, rollback-safe events,
late join, reconnect, visual scripting, examples, and clean package tooling.

No Unity compatibility range will be listed until the complete module validation
matrix passes.

The development source includes a machine-readable package plan, but it is not
a release artifact: its module and examples hashes remain null until the exact
Core contract is pinned and serialized export proof completes.
